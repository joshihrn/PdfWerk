PdfWerk

Everything you need to do to a PDF,
as a UI and as an API.

Create PDFs from text or Word, edit the text inside them, design and fill form fields, merge documents and summarise them. Use the tools below, call the same endpoints directly, or drop the widget into your own app. Open source, MIT licensed.

API reference Action catalogue GitHub

What it does

Try it

Create a PDF from text or Markdown

Headings, lists, tables, code blocks and links are all rendered.

Inspect a PDF

Page count, metadata, page sizes and every form field it contains.

Merge PDFs

Select two or more files; they are combined in the order chosen.

Word to PDF

Uses LibreOffice when available, otherwise the built-in .docx renderer.

Summarise a PDF

Extracts the text and asks a free model to summarise it. Long documents are split and merged automatically.
