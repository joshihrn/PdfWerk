PdfWerk embed

One script tag drops a working PDF tool into any page. This page is deliberately styled with Comic Sans, hot-pink buttons and orange inputs — none of which reach the widgets below, because each renders inside its own shadow root.

Install

<div id="pdf-create"></div>
<script src="/pdfwerk-embed.js"></script>
<script>
  PdfWerk.mount('#pdf-create', {
    tool: 'create',          // create | word | merge | summarize | fill | inspect
    apiKey: 'pw_…',          // optional; raises your quota
    delivery: 'preview',     // download | preview | callback
    theme: 'auto',           // light | dark | auto
    onResult: (blob, meta) => console.log('got', meta.fileName, blob.size)
  })
</script>

Options

OptionMeaning
toolWhich tool to render. Required.
apiKeyOptional. Without one the caller is on the anonymous tier.
baseUrlWhere the API lives. Defaults to the origin serving the script, so cross-origin embedding just works.
deliverydownload saves the file, preview renders it inline, callback hands it to your code only.
onResultAlways fires with the finished Blob, whatever the delivery mode.
onDataFires for JSON tools (summarize, inspect).
theme, titleAppearance. auto follows the host page's colour scheme.
